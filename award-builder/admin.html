Suspending takes effect on the server immediately, including for customers who are already signed in. Plan and status can only be changed here; customers cannot change their own. Every change is recorded in the audit table.

Download blocks by IP address

A block stops manufacturing-file downloads only from one IPv4 or IPv6 address, for every account using it, including people already signed in. They can still open the site, sign in and use previews. Shared networks: offices, schools, cafés and mobile carriers can put many customers behind one address, so a block can affect people you did not intend. Changing networks: someone who switches connection (mobile data, another Wi-Fi, a VPN) gets a different address, so an IP block alone cannot stop a determined person; suspend the account too. Restoring an IP never lifts an account suspension or a plan limit.
